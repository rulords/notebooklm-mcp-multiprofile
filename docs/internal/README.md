# 📁 Documentos Internos

Esta carpeta contiene la bitácora y documentación del proceso de investigación y desarrollo que llevó a la configuración actual del proyecto.

**Son documentos de referencia histórica**, útiles para entender las decisiones de diseño, pero no son necesarios para usar el proyecto.

## Contenido

- `BITACORA_ACTUALIZACION.md` — Registro cronológico de versiones probadas y errores encontrados
- `REPARACION_AUTH_MULTIPERFIL.md` — Post-mortem del proceso de reparación de autenticación multi-perfil
- `INDICE_RAPIDO_IA.md` — Índice de estado operativo (referencia para agentes AI)
- `AUDITORIA_HERRAMIENTAS_MCP.md` — Comparativa de herramientas entre versiones del motor
- `KB_AUTENTICACION_NOTEBOOKLM.md` — Base de conocimiento sobre autenticación persistente
- `COMPARATIVA_ESTRUCTURA_NUEVA.md` — Análisis comparativo de estructuras de configuración
- `ROADMAP_MIGRACION_NOTEBOOKLM.md` — Plan de migración entre versiones del motor
- `MEJORAS_SKILL_NOTEBOOKLM.md` — Mejoras implementadas en la Skill de Antigravity
- `CAPACIDADES_SKILL_NOTEBOOKLM.md` — Documentación de capacidades de la Skill
- `GUIA_HERRAMIENTAS_NOTEBOOKLM.md` — Referencia de herramientas del MCP
- `INSTALACION_NOTEBOOKLM_MCP.md` — Registro de la instalación original (v0.1.15)
